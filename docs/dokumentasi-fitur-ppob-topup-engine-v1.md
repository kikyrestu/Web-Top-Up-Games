## 🧠 1. Core Engine: Smart Price & Routing Logic
Sistem inti yang mengelola pengambilan produk secara otomatis dari 3 Provider utama: **Digiflazz, Rajabiller, dan Orderkuota**.

### ⚡ Game Top-Up Comparison (Smart Fetch)
* **Real-time Tri-Provider Sync:** Sinkronisasi produk dari 3 API sekaligus.
* **Lowest Price Detection:** Algoritma otomatis membandingkan harga modal dan menetapkan harga terendah sebagai basis jual.
* **Failover Protection:** Jika provider termurah *down*, sistem otomatis mengalihkan pesanan ke provider aktif berikutnya.

### 💰 Multifinance Smart Logic (Cicilan/Tagihan)
* **Admin-Zero Priority:** Prioritas utama diberikan kepada provider dengan **Biaya Admin Rp 0** untuk daya tarik "Gratis Admin" ke pelanggan.
* **Highest Commission Routing:** Jika biaya admin setara, sistem otomatis memilih provider dengan **Komisi (Kickback) Tertinggi** bagi pemilik platform.

## 🛡️ 2. Hybrid Authentication & Security
Sistem yang mendukung kenyamanan belanja cepat (Guest) maupun keamanan akun (User).
* **Login OTP (WA/Email):** Autentikasi modern tanpa password. Sangat aman dari brute-force dan memudahkan user karena tidak perlu menghafal password.
* **Guest Checkout Support:** User bisa belanja instan tanpa login.
* **Device Fingerprinting:** Teknologi pengenalan perangkat unik untuk melacak riwayat belanja meskipun dilakukan tanpa login (Guest Mode).
* **Auto-Sync Transaction:** Saat user akhirnya login/registrasi, sistem secara otomatis menarik riwayat belanja 'Guest' sebelumnya ke dalam akun user berdasarkan kecocokan No. WA atau Fingerprint perangkat.
